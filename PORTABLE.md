# Gesture Control — Windows x64 portable

1. Распакуйте ZIP целиком в доступную для записи папку, например Documents\GestureControl.
2. Запустите GestureControl.exe. Отдельная установка Python и загрузка модели не нужны.
3. Выберите камеру и нажмите «Включить». Покажите открытую ладонь для активации.

Не переносите только EXE: папка _internal содержит необходимые библиотеки и модель.
Крестик и сворачивание скрывают окно в трей. Полное завершение — «Выход» в меню значка рядом с часами.
Ctrl+Alt+G — аварийная пауза. После ошибки ввода нажмите «Продолжить», затем покажите ладонь.
Личные настройки, профили камер и logs хранятся рядом с EXE; пользовательские данные разработчика в архив не включены.
Приложение не запускает камеру автоматически и не требует администратора для обычного запуска.
Для первого запуска используются settings.example.json; «Сохранить» создаёт settings.user.json.

Проверка комплекта без камеры и управления мышью:
GestureControl.exe --self-test
Результат будет записан рядом с EXE в self-test.json. SELF_TEST_REPORT.json — отчёт при сборке.

Ограничения: сборка без цифровой подписи, Windows может показывать предупреждение о неизвестном издателе.
Проверки на чистой системе без установленного Python и на другом компьютере требуют отдельного прогона.
Работа камеры, задержки и права ввода зависят от оборудования и настроек Windows.

Воспроизводимая сборка из исходников:
.venv\Scripts\python.exe -m pip install -r requirements-cv-win-py314.lock.txt -r requirements-build.txt
.\build-portable.ps1

Сборка создаётся в новой папке dist с датой и временем; существующие сборки и настройки не перезаписываются.
Внутри ZIP есть SHA256SUMS.txt, рядом с ZIP — контрольная сумма архива.
THIRD_PARTY_LICENSES содержит доступные файлы лицензий зависимостей сборочного окружения.
