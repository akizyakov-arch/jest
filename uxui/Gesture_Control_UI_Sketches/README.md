# Gesture Control UI Sketches

Файлы:
- 01_home.svg — главный экран и быстрые действия
- 02_gestures.svg — библиотека жестов и уровни сложности
- 03_camera_calibration.svg — камера, tracking и калибровка
- 04_settings.svg — настройки, профили и Visual FX

UX-принципы:
- минимальная зона клика/тапа: 44×44 px, основные действия 52–64 px;
- emergency stop всегда доступен;
- ACTIVE / PAUSED видны без перехода в настройки;
- базовые жесты отделены от Advanced / Expert;
- Visual FX — отдельный слой и не влияет на gesture engine;
- интерфейс desktop-first, но структура пригодна для адаптации под macOS и Android.
