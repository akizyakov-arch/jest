# Проверка образца карты

## Область проверки

Основной результат задачи — географические тайлы и стиль, а не копия главного
экрана мобильного приложения. Просмотр предназначен для оценки реальной карты.
Источник визуального направления: первая карта Дона в сообщении пользователя
(1092 × 796) и мобильный референс из той же беседы. Локального оригинального
файла референса нет; нормализованная парная пиксельная проверка не выполнялась.

## Проверенный результат

- `../preview-final-desktop.png`: Chromium, 1440 × 1000 CSS px, screenshot CSS scale.
- `../preview-mobile.png`: Chromium, 390 × 844 CSS px, screenshot CSS scale.
- Состояние: векторная карта с включёнными слоями, центр 39.455 / 47.142,
  масштаб 13.4. Настоящая география OSM, без демонстрационных людей и судов.
- Полный экран и береговые детали осмотрены; на узком экране нет горизонтального
  переполнения. Панель слоёв помещается в экран и прокручивается.
- Проверены zoom, переход к Елизаветинской, возврат, переключение подписей и
  растительности. Все связаны с состоянием карты. HTTP тайлов: 200, gzip,
  `application/vnd.mapbox-vector-tile`.
- В финальном состоянии нет ошибок или предупреждений браузера.
- Production-сборка проходит. Vite сообщает о крупном JS chunk MapLibre;
  это размер веб-просмотра, не размер нативного мобильного приложения.

## Визуальные поверхности

- Типографика: русский Noto Sans для карты, системный Arial для оболочки.
  Читаемые подписи с halo; шрифты карты локальные.
- Компоновка: полноэкранная карта; оболочка не претендует на повторение мобильного
  референса с погодой, людьми, SOS и нижней навигацией — они вне текущей задачи.
- Палитра: бирюзовая вода, зелёная суша, светлые берега; намеренно графичная.
- География: сохранены реальные острова и протоки. Декоративные кроны не
  являются данными о деревьях, а прибрежная полоса не означает глубину.
- Контент: реальные населённые пункты; дата исходного снимка OSM показана честно.

## Исправления за проверку

1. Исправлены координаты перехода к Елизаветинской по OSM.
2. Убрана лишняя центральная линия поверх полигонов крупных рек.
3. Фактура леса включается вместе со слоем растительности.
4. Версионированы URL тайлов: старый браузерный кеш не скрывает новую геометрию.
5. Убрана ложная метрика сетевого трафика; показана сумма gzip-размеров
   уникальных запрошенных тайлов с явным объяснением.
6. Добавлен favicon data URL; устранён 404.

## Оставшиеся различия с исходным референсом

- [P1 для точной копии] Нет живописной фотографической фактуры, мелких

  образец сознательно упрощает их; точное совпадение не заявляется.
- Формальная нормализованная парная проверка невозможна без доступного файла
