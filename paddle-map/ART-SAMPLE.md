# Художественный фрагмент — итерация 2

## Камера и мобильное превью

- `http://127.0.0.1:4173/?mobile=1` — предпросмотр размеров 390 × 844 (iOS)
  и 412 × 915 (Android) в браузере. Это не проверка нативного SDK.
- `http://127.0.0.1:4173/?embedded=1` — карта на всю страницу с мобильным
  стартовым ракурсом: наклон 40°, поворот −18°.
- Кнопки поворота меняют азимут на 30°, `N` возвращает север вверх.
- `2.5D` переключает наклон 0° / 40°. В панели слоёв есть слайдер 0–55°.
- MapLibre обрабатывает поворот правой кнопкой мыши и стандартные touch-жесты.
- Возврат к общему виду сбрасывает наклон и поворот. Выбор населённого пункта
  сохраняет ракурс. Смена палитры тоже сохраняет камеру.

Это перспективное отображение плоской художественной подложки: реального
рельефа, геометрических деревьев и поднятых зданий не добавлено. Объём крон
остаётся нарисованным в текстуре. Размер растрового набора прежний — 431 КиБ,
но при повороте/наклоне может меняться число запрашиваемых тайлов.
Снимок: `preview-mobile-25d.png`.

## Обновление: прохладная версия

По обратной связи пользователя добавлена новая обработка встроенным ImageGen:
меньше жёлтого, глубже синий цвет воды, более объёмные группы крон, мягче кромка
берега. Прохладная версия открывается по умолчанию. Кнопки «Прохладная», «Тёплая»,
«Векторная» сравнивают один и тот же кадр без перемещения камеры.

Новые файлы: `public/raster-cool/`, `public/art-cool/stats.json`,
`public/style-art-cool.json`, `data/art/generated-atlas-cool.png`.
Точный запрос: `data/art/PROMPT-COOL.txt`.

25 новых тайлов: **441 798 байт (431,44 КиБ)**, на **8,35% меньше** тёплой
версии при той же рамке, масштабах, размере и параметрах WebP.
Это вес только растровой подложки, без векторных слоёв, шрифтов и интерфейса.
Оригинал генерации 1254 × 1254; увеличение карты не добавляет новых деталей.
Сохраняются ограничения географической достоверности художественного образца.

Сборка: `node scripts/build-raster.mjs --cool`.
Проверка: `node scripts/verify-raster.mjs --cool`.
Проверены все тайлы, переключатели, узкий экран, переход к краю участка.
Исправлен запрос несуществующего соседнего ряда на точной границе XYZ.
Production build проходит, после исправления ошибок карты в браузере нет.

Ниже сохранено описание первой, тёплой версии.

В просмотре по умолчанию открывается новая подложка. Переключатель
«Художественная / Векторная» сравнивает оформление при неизменном положении
камеры. Перемещение в этой версии ограничено рамкой художественного фрагмента.
Названия берутся из прежних MVT и остаются самостоятельными слоями.

## Результат

- `public/raster/{z}/{x}/{y}.webp` — 25 WebP-тайлов, масштабы z11–14,
  256 × 256 px, WebP quality 83.
- Полный растровый набор: **482 034 байта, 470,74 КиБ**. Это небольшой участок
  примерно 6,6 × 6,6 км, а не прежний векторный район размером 23 × 21 км.
- z14: 16 тайлов, 360 882 байта. Остальные 9 тайлов — нижние масштабы.
- На проверенном экране 390 × 844, z13.8: запрошены растровые файлы суммарно
  81 990 байт и векторные gzip-файлы суммарно 138 832 байта. Это сумма размеров
  файлов, без интерфейса, шрифтов, HTTP и учёта кеша.
- `public/style-art.json` — стиль подложки и векторных подписей; использует
  также исходные `public/tiles` и `public/fonts`.
- `public/art/atlas.webp` — цельный оптимизированный атлас для просмотра.
- `data/art/generated-atlas.png` — оригинальная генерация встроенного ImageGen.
- `data/art/PROMPT.txt` — точный запрос, `data/art/georeference.json` — привязка.
- `preview-art-desktop.png`, `preview-art-mobile.png` — снимки реального просмотра.
- `preview-art-geometry.png` — диагностическое наложение полигонов воды OSM.

## Способ получения

Из реальной карты OSM захвачен фрагмент без подписей (4 × 4 тайла z14,
2048 × 2048 экранных пикселей). Встроенный ImageGen выполнил художественную
обработку: растительность, кроны, пойма и бирюзовая вода. Полученный оригинал
имеет размер 1254 × 1254 px; для нативного уровня пирамиды он уменьшен до
1024 × 1024 px, затем нарезан. Никакого добавления детализации увеличением нет.
При дальнейшем приближении MapLibre увеличивает существующие тайлы (overzoom).

Вся генерация выполнена одним атласом, а не независимо по каждому тайлу:
так на стыках не появляются разные деревья, цвета воды и несовпадающие берега.
Sharp используется только для технической упаковки, масштаба и кодирования.

## Точность и визуальные ограничения

Это **художественный образец**, не спутниковая съёмка и не проверенная
навигационная карта. Общая форма рек и островов узнаваема и визуально
совмещается с OSM, но мелкие берега, ширина каналов, деревья, застройка и
тонкие линии в воде могли быть изменены/добавлены генерацией. Диагностическое
наложение — визуальная проверка, не геодезическая сертификация. Некоторые
границы соседних водных полигонов могут выглядеть как линии поперёк реки.

Кнопка «Сверить берега с OSM» в панели слоёв выводит исходные границы полигонов
воды; они могут включать внутренние границы соседних полигонов. Не считайте
каждую такую линию берегом. Для выпуска нужна независимая проверка геометрии
и контролируемая обработка по маскам реальных данных.

Новый образец ближе к референсу по фактуре и объёму; пиксельное совпадение
не заявляется. Изображение остаётся ограниченным по исходной детализации.

## Сборка

```powershell
node scripts/build-raster.mjs
node scripts/verify-raster.mjs
npm --prefix viewer run build
```

Повторная генерация изображения не нужна: исходник сохранён в проекте.
Веб-просмотр стартует прежней командой `npm run dev`. Android/iOS не проверялись.
Сохраняйте атрибуцию OSM; условия геоданных — в `DATA-LICENSE.md`.
