# PADDLE — векторная карта дельты Дона

**Обновление 23.09.2026:** добавлен художественный растровый фрагмент и
переключатель сравнения с векторной картой. Просмотр открывает новую версию.
Описание, размеры и ограничения: [ART-SAMPLE.md](ART-SAMPLE.md).
Ниже описана сохранённая исходная векторная версия.

Рабочий образец района Азова и Елизаветинской: реальные данные OpenStreetMap,
MVT-тайлы и собственный стиль MapLibre. Подложка полностью векторная: спутниковых
изображений и растровых текстур нет. Кроны — декоративные векторные точки внутри
реальных контуров леса, а не координаты отдельных деревьев.

## Что готово

- `public/style.json` — стиль MapLibre v8, 19 слоёв.
- `public/tiles/{z}/{x}/{y}.pbf` — обычные MVT, схема XYZ, масштабы 9–15.
- `public/tiles/{z}/{x}/{y}.pbf.gz` — те же тайлы, сжатые gzip для HTTP/CDN.
- `public/fonts/` — локальные glyph PBF, включая кириллицу, и лицензия шрифтов.
- `public/tilejson.json` — описание набора и слоёв.
- `public/stats.json`, `public/tile-sizes.json` — измеренные размеры файлов.
- `output/paddle-don.mbtiles` — один файл с тайлами для хранения/тайлового сервера.
- `output/paddle-don-map.zip` — тайлы, стиль, шрифты и документация.
- `viewer/` — работающий React/MapLibre GL JS просмотр. Это проверка карты,
  а не готовое React Native приложение.

Границы: запад 39.27, юг 47.065, восток 39.57, север 47.255.
Площадь рамки примерно 23 × 21 км. При приближении после z15 используется
увеличение подготовленной геометрии (overzoom), новых данных z16–17 нет.

## Размеры

1 018 тайлов: 9 554 411 байт без сжатия; 4 759 824 байта gzip (4,54 МиБ)
за все масштабы и весь участок. Шрифты, стиль и интерфейс считаются отдельно.
На первоначальном виде 1440 × 1000 при z13.4 запрашивалось 9 тайлов,
суммарный размер их gzip-файлов — 285 697 байт (279 КиБ).
Это не обещание расхода для любого телефона: кадр, масштаб, prefetch и кеш
меняют набор запросов. В панели просмотра показана сумма gzip-размеров
уникальных запрошенных тайлов, а не измеритель сетевого трафика с учётом кеша.

## Запуск просмотра

Из каталога `paddle-map`:

```powershell
npm install
npm --prefix viewer install
npm run dev
```

Адрес: http://127.0.0.1:4173/ . Сервер Vite отдаёт `.pbf.gz` как `.pbf`
с `Content-Encoding: gzip`, если браузер поддерживает сжатие.

Переключатели: названия, дороги, застройка, растительность, оформление берегов.
Есть приближение, отдаление, переход к Азову/Елизаветинской, возврат к общему
виду и выбор подписанного объекта. Живые люди, маршруты и лодки намеренно
не добавлены: этот образец посвящён карте.

## Подключение к React Native / MapLibre Native

Разместите содержимое `public` на своём сервере или CDN. В загружаемом объекте
стиля замените относительные адреса `sources.don.tiles` и `glyphs` абсолютными
HTTPS-адресами вашего сервера. Пример:

```js
style.sources.don.tiles = ['https://maps.example.com/don/v1/tiles/{z}/{x}/{y}.pbf'];
style.glyphs = 'https://maps.example.com/don/v1/fonts/{fontstack}/{range}.pbf';
```

Затем передайте стиль в установленный MapLibre React Native SDK. Стиль использует
обычные fill, line, circle, symbol и zoom expressions, но Android/iOS в этом
образце не запускались: фактическую плавность и совпадение рендеринга надо проверить
на устройствах. Не нужно прогонять каждый тайл через бизнес-API на Go.

Для CDN: `Content-Type: application/vnd.mapbox-vector-tile`; для заранее сжатого
файла обязательно `Content-Encoding: gzip`. Не сжимайте `.gz` второй раз.
Настройте CORS для веб-просмотра. Для длительного кеша используйте версионированный
путь (`/don/v1/...`) и меняйте версию при обновлении набора. В просмотре есть
cache-busting параметр ревизии.

MBTiles содержит gzip-MVT и строки TMS (`tile_row = 2^z - 1 - y`). Это формат
хранения, не готовый URL для мобильного SDK: потребуется поддерживающий MBTiles
сервер либо отдельный офлайн-адаптер. Стиль и шрифты лежат отдельно.

## Воспроизведение сборки

```powershell
npm run data:fetch
npm run tiles:build
npm run style:build
node scripts/fetch-fonts.mjs
npm run verify
python scripts/package.py
npm --prefix viewer run build
```

Загрузка использует сохранённый `data/osm.json`; запрос не отправляется повторно,
если кеш уже есть. Запрос Overpass сохранён в `data/query.overpass`.
Для актуализации сохраните старый extract отдельно и загрузите новый.
Для больших территорий следует перейти с публичного Overpass на региональный
OSM PBF и промышленный конвейер генерации тайлов.

## Что проверено и ограничения

- Все 1 018 MVT декодированы, проверены gzip, версия формата, источники слоёв,
  наличие островных колец и населённых пунктов; результат в `verification.json`.
- Стиль прошёл валидатор MapLibre. Просмотр проверен в Chromium, включая слои,
  масштабирование и узкий экран.
- Это авторская **векторная интерпретация**, не пиксельная копия живописного
  референса: леса и вода более графичные, нет фотографических переходов.
- Полнота берегов и растительности зависит от OSM. Не добавлялись вымышленные
  протоки, глубины или судовые данные. Светлая полоса берега — оформление.
- Источник скачан 22.09.2026, но timestamp снимка базы использованного сервера —
  **31.05.2026 22:37:44 UTC**. Это явно записано в метаданных и в просмотре.
- За пределами рамки нет подготовленной карты. Просмотр ограничивает перемещение
  этой областью. Не оценивались расход батареи и производительность мобильного SDK.
