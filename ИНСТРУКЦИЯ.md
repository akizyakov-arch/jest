# Gesture Control — инструкция пользователя

Для Gesture Control dev42, Windows x64: запуск из проекта или portable-комплекта. Приложение управляет курсором и командами Windows по движениям руки перед камерой.

Актуально на 22 сентября 2026 года. Описание относится к стандартным назначениям жестов; сохранённые настройки могут их изменять.

## Краткая памятка

| Что нужно | Жест или действие |
|---|---|
| Начать управление | Покажите одну открытую расслабленную ладонь. |
| Левый / правый клик | Большой + указательный / большой + средний, затем разомкнуть. |
| Средний клик | Указательный и средний подняты, большой разомкнут, остальные согнуты. |
| Перетащить | Синяя рука: удерживать левый щипок и двигать ладонь. |
| Обзор окон и рабочих столов | Любая рука: соединить большой, указательный и средний на 0,3 с → золотая руна → движение вверх. |
| Показать рабочий стол / вернуть окна | Та же тройная щепотка → золотая руна → движение вниз. |
| Zoom | Левый щипок обеими руками почти одновременно → развести / сблизить руки. |
| Отмена / Esc | Кулак синей руки примерно на полсекунды. |
| Срочная пауза | Ctrl+Alt+G. |

**Цвет обозначает роль, а не левую или правую руку.** Одна рука — синяя. Вторая — красная, если включена опция «Вторая рука». Золотая руна означает готовность жеста управления окнами.

## 1. Первый запуск

1. Распакуйте **весь ZIP-архив** в отдельную папку, например `Документы\GestureControl`.
2. Запустите `GestureControl.exe`. Устанавливать Python или скачивать модель не нужно.
3. Дождитесь появления списка камер. Выберите встроенную или внешнюю камеру.
4. При необходимости отметьте **«По умолчанию»**, чтобы сохранить выбор камеры.
5. Нажмите кнопку включения камеры. На главном экране появится изображение.
6. Покажите одну открытую ладонь и ненадолго задержите её. Состояние **ACTIVE** означает, что управление включено.

Не переносите EXE отдельно от папки `_internal`: в ней находятся необходимые библиотеки и модель.

Если запускаете из папки проекта, откройте PowerShell и выполните:

```powershell
cd D:\DEVV\Jest
.\run-control.ps1
```

Перед запуском другой версии завершите предыдущую через меню трея → **«Выход»**.

Поставьте камеру так, чтобы в кадре помещалась кисть вместе с запястьем. Свет лучше направить на руку, а не в объектив. Ладонь может быть расслабленной, пальцы — слегка согнутыми; напрягать и полностью выпрямлять их не требуется.

## 2. Основные жесты

Назначения ниже соответствуют стандартным настройкам. Некоторые жесты можно отключить или изменить в интерфейсе.

| Действие | Как выполнить |
|---|---|
| Включить управление | Покажите открытую ладонь, большой и указательный пальцы разомкнуты. |
| Двигать курсор | Перемещайте ладонь. По умолчанию курсор привязан к её центру. |
| Левый клик | Коротко соедините большой и указательный пальцы, затем разомкните. |
| Двойной клик | Выполните два последовательных левых щипка в одной точке. На синей руке есть стабилизация точки двойного клика. |
| Перетащить объект | Синей рукой наведитесь, соедините большой и указательный пальцы, удерживайте щипок и двигайте ладонь. Разомкните пальцы для отпускания. |
| Правый клик | Коротко соедините большой и средний пальцы. Если в настройках выбран безымянный — используйте его. |
| Средний клик | Поднимите указательный и средний пальцы, большой держите разомкнутым, остальные согните. Удержите жест на короткий момент. Для следующего клика сначала опустите пальцы. |
| Отмена / Esc | Сожмите кулак и удерживайте примерно полсекунды. Разожмите для повторного выполнения. |
| Переключить приложение | Выполните смахивание кистью, описанное ниже. |
| Открыть экранную клавиатуру | Нажмите **«Клавиатура»** на главном экране. Вызов тремя пальцами отключён. |

**Два пальца отправляют один средний клик.** Длительное удержание этого жеста не удерживает среднюю кнопку и не включает перетаскивание.

### Смахивание кистью

Можно использовать обе руки; для красной включите «Вторая рука». Представьте короткий прощальный взмах: поверните кисть вокруг запястья в сторону примерно на **30–45°**, в том числе немного ребром к камере. Запястье можно почти не двигать. Начните с движения длительностью около полсекунды, без сильного рывка.

- Левой рукой — назад, `Alt+Shift+Tab`, независимо от цвета руны и направления взмаха.
- Правой рукой вправо в зеркальном предпросмотре — `Alt+Tab`, влево — `Alt+Shift+Tab`.
- Один взмах вызывает одно переключение. Верните руку и сделайте короткую остановку перед следующим.
- Простой перенос всей руки без поворота кисти не считается смахиванием.

Это системные сочетания Windows: порядок приложений определяет Windows. Во время клика и перетаскивания смахивание не должно переключать приложения. Не соединяйте пальцы в щипок одновременно с взмахом.

Если появляются случайные переключения, отключите **«Переключение окон»** в разделе **«Жесты → Дополнительные»**.

### Вторая рука и красная руна

**Плавность и дрожание:** на главном экране в блоке «Плавность» включите «Антидрожь», затем сохраните настройки и возобновите управление. По умолчанию опция выключена. Она удерживает цель при колебаниях в пределах 3 пикселей, но пропускает накопившееся небольшое движение и достижение краёв экрана. Сглаживание регулирует плавность движения; антидрожь отдельно подавляет мелкий шум положения. Обе руны используют эти настройки. Диапазон скорости на главном экране расширен до 10; для более быстрого отклика также можно уменьшить значение «Сглаживание, мс».

Кольцо нажатия относится только к выполняющей действие руне. Красная руна больше не повторяет индикацию синего щипка. Уже выбранная вторая рука не теряет щипок только из-за краткого снижения уверенности определения стороны, пока камера непрерывно видит ту же сторону и близкое положение ладони.

Включите **«Вторая рука»** на главном экране или **«Вторая рука / Zoom»** в разделе **«Жесты → Профессиональные»**. Нажмите **«Сохранить настройки»**, чтобы оставить выбор после перезапуска. По умолчанию опция выключена. Её можно отключить в любой момент; изменение настроек приостанавливает управление.

Сначала активируйте управление одной основной рукой, затем покажите вторую. Основная рука сохраняет синий курсор. Вторая получает красную руну — это индикатор положения руки, а не второй системный курсор. Для устойчивого определения не перекрещивайте руки и держите их отдельно друг от друга. После полной потери основной руки сначала верните одну открытую ладонь для восстановления.

**Клики основной рукой выполняются в синей точке, второй — в красной, независимо от стороны.** В настройках выбран режим FIRST (первая обнаруженная). Одна видимая рука — синяя. При появлении второй она получает красную руну. Если синяя рука исчезла, ненадолго покажите оставшуюся открытую ладонь: она станет синей после восстановления отслеживания. При левом или правом клике второй рукой Windows-указатель перемещается к красной руне, нажимает кнопку и возвращается в синюю точку. После среднего клика он остаётся под управлением красной руки для автопрокрутки; синяя руна сохраняет прежнюю позицию. Если используете старый конфиг с привязкой LEFT или RIGHT, выберите автоматический режим FIRST в настройках. Жесты второй руки:

- Большой + указательный, затем разомкнуть — левый клик.
- Удерживайте большой с указательным и двигайте ладонь — перетаскивание окна или объекта красной руной. Разомкните, чтобы отпустить.
- Для совместимости с веб-играми левое нажатие красной руны выполняется не ранее чем через 40 мс после наведения. После отпускания указатель остаётся в красной точке ещё 120 мс перед возвратом к синей. Камера и распознавание продолжают работать; потеря руки или пауза отменяет ещё не выполненное нажатие.
- Большой + средний, затем разомкнуть — правый клик (или безымянный, если выбран в настройках).
- Поднять указательный и средний, оставив большой разомкнутым — один средний клик; опустить перед повтором.

Перед первым кликом раскройте вторую руку. Левый щипок нажимает кнопку в красной точке и удерживает до размыкания; небольшие движения отфильтровываются, заметное перемещение ладони начинает drag. Синяя руна в это время сохраняет свою позицию. При потере отслеживания или паузе кнопка отпускается; перед новым захватом раскройте щипок. Правый клик остаётся парой нажатие/отпускание при размыкании, после которой курсор задерживается в красной точке на 250 мс для открытия меню. Уже удерживаемая кнопка любой руки имеет приоритет: вторая рука не перехватывает её. Два щипка обеими руками запускают Zoom, только если сделаны до захвата кнопки. Выключение второй руки отключает её клики, перетаскивание, смахивания и жесты рабочих столов.

Чтобы масштабировать содержимое окна:

1. Наведите основной курсор на нужное окно или область.
2. Соедините большой и указательный пальцы **на обеих руках почти одновременно** и удерживайте около четверти секунды.
3. Разведите руки для увеличения масштаба, сблизьте для уменьшения.
4. Разомкните щипок любой руки, чтобы закончить. Перед следующим действием раскройте основную руку.

Масштабирование отправляет Ctrl + колесо мыши. Его результат зависит от поддержки такого сочетания программой. При входе в Zoom левый клик не отправляется. Уже начатое перетаскивание не переключается на Zoom. Потеря второй руки завершает масштабирование. Одиночный щипок не получает дополнительной задержки только из-за присутствия второй руки. Если нажатие уже началось, сначала разомкните пальцы и повторите оба щипка почти одновременно для Zoom.

### Щепотка любой руки вверх / вниз

Включение и отключение: **«Жесты → Дополнительные → Рабочие столы»**.

На синей руке жест доступен и без второй руки. Для красной включите вторую руку. **Соедините большой, указательный и средний пальцы на 0,3 секунды, дождитесь золотистой руны**, затем выполните вертикальное движение:

- **Вверх** — обзор открытых приложений и виртуальных рабочих столов Windows (`Win+Tab`).
- **Вниз** — показать рабочий стол или вернуть окна (`Win+D`).

Одна щепотка вызывает одно действие. При одновременной тройной щепотке обеих рук приоритет у синей; команда не дублируется. Уже начатые перетаскивание и Zoom не перехватываются. Разомкните оба контакта перед следующим; одной остановки недостаточно. Обычное наведение раскрытой ладонью с отведённым большим пальцем не предназначено для этих команд. Действие «вниз» не закрывает программы. Жесты обзора не выполняются во время Zoom или удержания кнопки мыши.

## 3. Прокрутка

По умолчанию два пальца назначены на **среднюю кнопку мыши**. В приложениях с автопрокруткой (например, по свободному месту страницы браузера) средний клик включает её.

- После среднего клика синей рукой двигайте синюю ладонь для управления прокруткой. Красная рука не перехватывает этот режим.
- После среднего клика красной рукой двигайте красную ладонь. Движения синей руки не меняют прокрутку; синяя руна остаётся на месте.
- Для остановки любого режима сделайте щипок, повторный средний жест или удержите кулак около 0,25 секунды **той рукой, которая включила прокрутку**. Другая рука не останавливает и не перехватывает её. Жест завершает прокрутку без дополнительного клика. После него разомкните пальцы перед обычным кликом. Общая кнопка «Пауза» и Ctrl+Alt+G работают независимо от руки.
- Пауза, смена камеры или выход завершают активную прокрутку через Esc. Красный режим переносит краткий пропуск распознавания до 150 мс; длительная потеря завершает его. Системный указатель возвращается в сохранённую синюю точку.

Приложение не получает от браузера подтверждение включения автопрокрутки: режим управления начинается после любого среднего клика. Если средний клик открыл ссылку во вкладке вместо прокрутки, завершите режим тем же жестом остановки. Пока режим активен, обычные клики, Zoom и золотой жест не выполняются; сначала закончите прокрутку.

Это поведение самого приложения: оно может отличаться в браузере, редакторе и других программах. Средний клик по ссылке, например, может открыть её в новой вкладке вместо прокрутки.

В разделе **«Жесты»** можно изменить назначение двух пальцев со средней кнопки на **«Прокрутка»**. Это прежний режим для синей руки: два поднятых пальца и вертикальное движение руки управляют колесом прокрутки. Эти два назначения выбираются по очереди. Отдельного универсального режима «открытая ладонь листает любое окно» в текущей версии нет.

## Центр руны и стандартный курсор Windows

Белая точка с тёмной обводкой в центре каждой руны — точное место наведения и клика. Точка видна на синей, красной и золотой руне в режимах Full и Minimal и не вращается вместе с рисунком.

Чтобы убрать стандартный указатель, откройте **«Опции → Visual FX»**, нажмите **«Курсор Windows: показывать»**, чтобы переключить на **«скрывать»**, и сохраните настройки. После изменения возобновите управление открытой ладонью. По умолчанию скрытие выключено.

Стандартные курсоры скрываются только при активном отслеживании и отрисованной руне. При паузе, потере отслеживания, выключении эффектов или закрытии они возвращаются. Исходные формы курсоров сохраняются в отдельном процессе контроля ввода и восстанавливаются также при потере связи с приложением. Собственные нестандартные указатели отдельных программ могут оставаться видимыми.

## 4. Настройка удобного наведения

**«Точное наведение»** на главном экране включает адаптивное сглаживание: медленное наведение сглаживается сильнее, быстрое движение получает меньшее отставание. Для сравнения режим можно выключить.

Начните с двух ползунков на главном экране:

- **Скорость курсора:** уменьшите, если курсор слишком резко перемещается; увеличьте, если он не успевает за рукой.
- **Сглаживание, мс:** увеличьте при дрожании. Большое значение делает движение плавнее, но добавляет ощущение задержки.

Меняйте по одному параметру небольшими шагами и проверяйте наведение на одну и ту же кнопку. После настройки нажмите **«Сохранить настройки»**.

### Рабочая область

Рабочая область — часть изображения камеры, которая соответствует всему экрану.

- Если приходится слишком далеко тянуться рукой, **уменьшите рабочую область**.
- Если небольшое движение руки слишком сильно смещает курсор, **увеличьте рабочую область**.
- Область 100% использует практически весь кадр и требует более широкого движения руки.

Откройте **«Камера и калибровка»** и настройте ширину и высоту либо выполните калибровку:

1. Нажмите **«Начать калибровку»**.
2. Следуйте подсказкам для центра и четырёх удобных краёв.
3. В каждой точке удерживайте выбранный якорь курсора — по умолчанию центр ладони — около полсекунды и нажимайте **«Зафиксировать точку»**.
4. Сохраните профиль камеры и общие настройки.

Во время калибровки управление приостанавливается. Сворачивание окна в трей отменяет незавершённую калибровку.

Изменение настроек управления может поставить приложение на паузу. Нажмите **«Продолжить»**, затем снова покажите открытую ладонь.

## 5. Пауза и потеря руки

**Быстрая остановка — `Ctrl+Alt+G`.** Это стандартное аварийное сочетание; если вы изменили его в настройках, используйте выбранное.

Также можно нажать **«Пауза»** в окне или меню трея. Для возвращения после ручной паузы нужны кнопка **«Продолжить»** и открытая ладонь.

После обычной потери руки камерой достаточно вернуть одну открытую ладонь и немного задержать её. Прежнее перетаскивание при этом не возобновляется: нужно сделать новый щипок.

Руна может ещё некоторое время оставаться видимой после потери руки. Это визуальное ожидание, а не признак продолжающегося управления.

| Состояние | Значение |
|---|---|
| OFF | Управление выключено. |
| STANDBY | Приложение ожидает активации ладонью. |
| ACTIVE | Управление активно. |
| PAUSED | Управление приостановлено. Смотрите подсказку в окне. |

## 6. Работа в трее

Крестик и кнопка сворачивания скрывают окно, **но не выключают камеру и управление**.

Найдите значок голубой руны рядом с часами Windows. Он может находиться под стрелкой скрытых значков.

- Нажатие на значок возвращает окно.
- Правый клик открывает меню управления, паузы, камеры, эффектов и настроек.
- **«Выключить камеру»** останавливает камеру, оставляя приложение открытым.
- **«Выход»** полностью завершает приложение и освобождает его ресурсы.

Если трей недоступен, крестик закрывает приложение обычным способом. Если сервис трея перестаёт работать при скрытом окне, приложение пытается восстановить окно.

## 7. Сохранение и перенос настроек

В portable-версии пользовательские файлы находятся рядом с `GestureControl.exe`:

- `settings.user.json` — сохранённые настройки;
- `camera-default.json` — выбор камеры по умолчанию;
- `camera-*.json` — сохранённые профили камер;
- `logs` — диагностические журналы.

При первом запуске используются настройки примера; пользовательский файл создаётся после сохранения.

Чтобы сохранить привычные параметры при обновлении, закройте приложение, распакуйте новую версию в отдельную папку и перенесите туда `settings.user.json`. На том же компьютере можно также перенести файлы камеры. На другом компьютере заново выберите камеру и проверьте рабочую область.

Для переноса настроек из версии, запускаемой через Python, скопируйте её `settings.user.json` в папку рядом с portable-EXE, предварительно завершив оба экземпляра приложения.

## 8. Если что-то не работает

**Камера не появилась или изображение чёрное.** Обновите список камер, проверьте выбранное устройство и повторите запуск. Закройте другую программу, которая может занимать камеру, и проверьте разрешение Windows на доступ к камере.

**Рука видна, но курсор не двигается.** Посмотрите состояние. После ручной паузы сначала нажмите «Продолжить». Покажите одну открытую ладонь с разомкнутыми большим и указательным пальцами. Убедитесь, что выбранная ведущая рука соответствует используемой.

**Курсор дрожит или трудно попасть в маленькую кнопку.** Улучшите освещение, уменьшите скорость, немного увеличьте сглаживание. Проверьте, не слишком ли мала рабочая область.

**Клик не получается или срабатывает другой жест.** Для левого клика соединяйте большой только с указательным, для правого — только со средним. Контакт со средним и указательным одновременно готовит золотой режим. Для среднего клика большой должен быть разомкнут. Перед первым кликом после появления руки раскройте её. Клик синей руки идёт в синюю точку, красной — в красную.

**Красная руна не появляется или не кликает.** Включите «Вторая рука», сначала активируйте одну ладонь, затем покажите вторую. Держите руки раздельно и в кадре. Красная руна может быть видна даже при неуверенном определении стороны руки, но команды требуют устойчивого распознавания двух разных рук.

**Золотая руна не появляется.** Проверьте «Жесты → Дополнительные → Рабочие столы». Соедините большой сразу с указательным и средним, задержите руку на 0,3 секунды без заметного движения. При Visual FX = Off цвет не отображается; выберите Full или Minimal. Активное перетаскивание или Zoom сначала нужно завершить.

**Золотой жест не повторяется.** Разомкните большой палец с обоими пальцами, затем заново сделайте тройную щепотку. Кулак и четыре поднятых пальца не вызывают обзор окон.

**Золотой режим мешает обычным кликам.** Разводите средний палец при левом щипке и указательный — при правом. При необходимости отключите «Рабочие столы»: это отключает тройную щепотку обеих рук.

**Смахивание пропускается.** Поворачивайте саму кисть, сохраняя запястье в кадре. Попробуйте поворот на 30–45° примерно за полсекунды. Не делайте щипок одновременно. Распознавание с тыльной стороны руки может быть менее устойчивым.

**Ошибка Input watchdog / disconnected.** Нажмите «Продолжить», затем активируйте управление ладонью. Если старый процесс ещё завершает работу, немного подождите и повторите. Если приложение сообщает, что освобождение ввода не подтверждено, завершите его через «Выход» и запустите заново. При повторении сохраните журнал из папки `logs`.

**Окно исчезло после крестика.** Это обычное сворачивание в трей. Найдите значок рядом с часами.

**Проверка portable-комплекта.** Из терминала в папке приложения выполните:

```powershell
.\GestureControl.exe --self-test
```

Проверка не включает камеру и не отправляет реальные клики. Результат появится в `self-test.json`; значение `"ok": true` означает, что встроенные проверки пройдены. Это не проверка качества распознавания вашей руки.

## 9. Что пока не реализовано

Полноценные профили управления 3D- и видеоредакторами, работа с несколькими мониторами и автозапуск вместе с Windows остаются следующими этапами. Эта сборка предназначена для Windows x64; на Android и macOS она не запускается.
